## 🚀 Key Features

- **✨ Premium Catalog**: Browse thousands of modern furniture items with high-resolution previews.
- **🛡️ Secure Auth**: Robust login and signup system with session-based cart persistence.
- **📊 Admin Power**: Comprehensive dashboard for product management, brand control, and sales reporting.
- **🛒 Seamless Checkout**: Effortless cart-to-payment transition with integrated gateway simulation.
- **📱 Ultra Responsive**: Optimized for every device, from mobile screens to large desktop monitors.

## 🔧 Installation

1. **Clone the Repo**
   ```bash
   git clone https://github.com/shreya-patil/furnless-copy.git
   ```
2. **Setup Database**
   - Restore the SQL database using the `furnlessDB` script.
   - Update `Web.config` connection string.
3. **Run Project**
   - Open in Visual Studio.
   - Run `index.aspx` as the start page.
